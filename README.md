# Cyclistic-2025-Analysis

## Project Objective

This project aims to understand behavioral differences between casual users and members of Cyclistic's bike-sharing service and identify opportunities to increase membership adoption.

## Tools Used

- Python (Pandas, Matplotlib, Seaborn)
- Tableau Public
- Google Sheets

## Project Files

- Full analysis notebook: Cyclistic_analysis_2025.ipynb
- Project report: Cyclistic 2025 Report.pdf
- Dashboard screenshot

## Key Insights

- Members use the service more frequently during weekdays
- Casual riders tend to take longer trips
- Casual usage increases during summer months
- Electric bikes are generally preferred
